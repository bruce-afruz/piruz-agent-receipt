# Contributing to PARP

We welcome independent implementations, deployment reports, security review and
specification feedback. The most valuable contribution is an implementation that
can verify a signed PARP manifest produced by another organization.

## Start here

1. Open a Discussion to describe the use case or implementation plan.
2. Open an issue before a large protocol change.
3. Fork the repository, make a focused change and send a pull request.
4. Add or update a test for any behavior change.

Do not submit private keys, access tokens, user prompts, personal data or
publisher content without permission. Contributions are offered under the MIT
License in this repository. By submitting one, you confirm that you have the
right to contribute it under that license.

## Interoperability reports

Please include the public deployment URL, implementation language, PARP version,
whether signature verification succeeded, and only non-sensitive test material.
Ask before listing a private deployment as an adopter.
